## 📁 Projects

### 🔹 Project 1 – Heart Disease Patient Analysis
📂 [`Project1_heartDiseaseProject`](Project1_heartDiseaseProject)
302 cardiology patients, 10 business problems, a Power BI dashboard and a stakeholder deck.
✔ Caught a **reversed outcome label** during validation · ✔ 46% of referred patients have heart disease · ✔ 62% of cases sit in a High-risk tier that is 30% of patients

---

### 🔹 Project 3 – Streaming & IMDb Ratings Analysis
📂 [`Project3_IMDb_movies_rating_title`](Project3_IMDb_movies_rating_title)
Exploratory analysis of the Netflix catalogue joined to IMDb movie ratings, with pandas, seaborn, matplotlib and plotly.
✔ Movies vs TV shows and when content was added · ✔ Netflix titles matched to IMDb ratings · ✔ Genres, countries and release years

---

### 🔹 Project 4 – Secure Boot Rollout: GP1 Coverage Check
📂 [`Project4_SecureBoot`](Project4_SecureBoot)
Reconciles 73 laptops that need a Secure Boot policy against the GP1 group that delivers it.
✔ **94.5%** covered · ✔ all 4 gaps are new SD-series laptops · ✔ traced to a missing step in the laptop imaging checklist

---

### 🔹 Project 5 – Laptop Lifecycle: 2026 Refresh Programme
📂 [`Project5_LaptopLifecycle`](Project5_LaptopLifecycle)
518 laptop replacements tracked from set-up to old-device return.
✔ **97.1%** shipped, median **3 days** set-up to ship · ✔ **303** old laptops still out · ✔ recovery ranges from 98% to 2% by province

---

### 🔹 Project 6 – UPS Monitoring Non-Compliance Audit
📂 [`Project6_NonCompliance`](Project6_NonCompliance)
Audits 71 UPS units protecting network racks at 52 sites.
✔ Only **45.1%** monitored · ✔ 11 remote fixes + one hardware order → over 90% · ✔ 3 sites hold 36% of the problem

## 🗂 How each project is organised
```
ProjectX_Name/
├── README.md            # business questions, findings, recommendations, charts
├── requirements.txt
├── data/raw/            # source data (anonymised where it came from real operations)
├── data/processed/      # cleaned data written by the notebook
├── notebooks/           # commented Jupyter notebook: validate → clean → analyse
├── images/              # charts used in the README
├── presentation/        # stakeholder deck with speaker notes
└── docs/                # data cleaning notes
```

## 🛠 Tools & Skills
- Python: pandas, matplotlib, seaborn, Jupyter
- Data validation and cleaning: duplicates, mixed date formats, inconsistent codes, reconciliation
- Business analysis: KPIs, root-cause analysis, findings and recommendations
- Power BI and PowerPoint for stakeholder reporting

## 🔒 Data privacy
Projects 4–6 use real IT operations data. Names, emails, employee IDs, serial numbers, asset tags, tracking numbers and internal IP addresses are replaced with consistent fake values before publishing. The original files are not part of this repository.
